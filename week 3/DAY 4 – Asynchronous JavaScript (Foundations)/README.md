##  Week Overview
Week 3 focuses on **advanced JavaScript concepts** required before moving to React.

Day 4 introduces **asynchronous JavaScript**, which is the backbone of API calls, data fetching, and side effects in React.

---

##  Day 4 – Asynchronous JavaScript (Foundations)

### Concepts Covered
- `setTimeout`
- Callbacks
- Asynchronous execution basics
- Non-blocking JavaScript behavior

---

##  Why This Matters
Modern web applications:
- Fetch data from APIs
- Handle delays (network, timers)
- Must not block the UI

React heavily depends on **asynchronous logic** to:
- Fetch data
- Update state
- Handle side effects smoothly

Understanding async JavaScript prevents confusion and bugs later in React.
