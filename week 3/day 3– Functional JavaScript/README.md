Week 3 focuses on **advanced JavaScript concepts** that are essential before learning React.

This day emphasizes **clean, predictable, and reusable logic** using functions instead of step-by-step code.

---

##  Day 3 – Functional JavaScript

### Concepts Covered
- Higher-Order Functions
- `map()`, `filter()`, `reduce()`
- Pure vs Impure Functions
- Reusable utility functions

---

##  Why This Matters
React applications rely on **functional logic**:
- Components are functions
- State updates must be pure
- Lists are rendered using `map`
- Data is filtered before rendering

Understanding functional JavaScript makes React **easy and predictable**.
