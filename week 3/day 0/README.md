Week 3 – Day 0
JavaScript UI to Node.js Console Conversion
 Week Overview

Week 3 focuses on preparing for React development by strengthening JavaScript fundamentals and moving from browser-based JavaScript to Node.js.
Day 0 is dedicated to converting existing UI-based JavaScript projects into pure console-based Node.js programs.

📅 Day 0 – Concepts Covered

Browser JavaScript vs Node.js
Removing DOM manipulation (document.getElementById)
Replacing UI output with console.log()
Running JavaScript files in the terminal
Understanding JavaScript independent of HTML/CSS

🔄 Work Done (UI → Console Conversion)

The following JavaScript programs were converted from UI-based (HTML + DOM) to Node.js console-based applications:

Largest of Three Numbers
Table Generator
Counter Application
Login Form Validation
student report card

All UI elements such as buttons, input fields, and DOM updates were removed and replaced with:

Terminal input
Console output
Menu-based interaction where required

▶️ How to Run Files Using Node.js

Open terminal in the project folder
Run the file using:

node filename.js

Example:
node largest_of_3.js
node table_generator.js
node counter.js

🧠 What I Learned

JavaScript can run outside the browser using Node.js
DOM manipulation is browser-specific
Logic can be tested without UI
Console-based programs improve logical thinking
This transition is essential before learning React
