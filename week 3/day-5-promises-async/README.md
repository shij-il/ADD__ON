# 📘 Week 3 – Day 5: Promises & async/await

##  Week Overview
Week 3 focuses on **advanced JavaScript concepts** required before starting React.
This week strengthens logical thinking, async handling, and clean code practices
needed for modern frontend development.

Day 5 introduces **Promises and async/await**, which are the standard way React
handles API calls, side effects, and asynchronous data flow.

---

##  Day 5 – Promises & async/await

### Concepts Covered
- Promises
- `.then()` and `.catch()`
- `async` / `await`
- Error handling using `try...catch`

##  Why This Matters
React applications frequently:
- Fetch data from APIs
- Handle delays and network failures
- Update UI based on async responses

Using Promises and `async/await` allows developers to:
- Write clean and readable async code
- Avoid callback confusion
- Handle errors safely
- Manage side effects correctly in React
