# 📘 Week 3 – Advanced JavaScript (Ready for React)

##  Week Overview
Week 3 focused on **Advanced JavaScript concepts** that are essential before starting **React.js**.  
This week emphasized **logic building, async programming, functional patterns, and real-world API usage**, with minimal UI and more focus on **clean JavaScript execution** using **Node.js**.

The goal was to transition from **browser-based JavaScript** to **modern JavaScript used in React and backend tooling**.

---

##  Goals of Week 3
- Strengthen JavaScript fundamentals deeply
- Learn modern ES6+ syntax used in React
- Understand execution context, scope, and closures
- Master asynchronous JavaScript
- Work with real APIs using Fetch
- Build confidence in logic without UI dependency
- Prepare fully for React development
