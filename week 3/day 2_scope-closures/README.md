# 📅 Week 3 – Day 2  
## Execution Context, Scope & Closures (JavaScript)

---

## 📘 Day Overview

Day 2 focused on understanding **how JavaScript executes code internally** and how variables behave in different scopes.  
These concepts are very important for debugging, writing clean code, and understanding **state behavior in frameworks like React**.

---

##  Concepts Covered

### 1️⃣ Execution Context (Basic Understanding)
- How JavaScript creates an execution environment before running code
- Memory allocation phase and execution phase
- Global execution context

### 2️⃣ Scope
- Global scope
- Function scope
- Block scope (`let`, `const`)
- Difference between `var`, `let`, and `const`

### 3️⃣ Hoisting
- Variable hoisting with `var`
- Temporal Dead Zone (TDZ) with `let` and `const`
- Function hoisting

### 4️⃣ Closures
- Functions remembering variables from their outer scope
- Data privacy using closures
- Real-world use cases like counters and state handling
