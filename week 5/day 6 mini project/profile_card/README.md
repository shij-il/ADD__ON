# 🧩 React Mini Project – Profile Card UI

This is a **simple React mini project** built as part of **Week 5 – Frontend Development using React**.  
The project focuses on understanding **React components, props, JSX, and basic styling** by building a clean **Profile Card UI**.

---

## 🎯 Project Objective
- Understand how React components work
- Pass data using **props**
- Build reusable UI components
- Apply basic CSS styling
- Create a simple and clean UI layout

---

## 🛠️ Technologies Used
- React (Vite)
- JavaScript (ES6)
- HTML
- CSS
- Node.js
- npm

---

## 📌 Features
- Reusable `Card` component
- Displays:
  - Profile Image (placeholder image)
  - Name
  - Role
- Renders **three different profile cards**
- Clean and responsive layout
- Beginner-friendly React structure
