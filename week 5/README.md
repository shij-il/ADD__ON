# 📘 Week 5 – Frontend Development (React Basics)

This repository contains my **Week 5 learning tasks** focused on **React fundamentals**, completed as part of my frontend development training.  
The goal of this week was to understand **React basics**, **JSX**, **components**, **props**, and to build a **simple React UI**.

---

## 🚀 Technologies Used
- React (Vite)
- JavaScript (ES6)
- HTML
- CSS
- Node.js
- npm

---

## 📅 Weekly Learning Overview

### ✅ Day 1 – Introduction to React & Setup
- Learned what React is and why it is used
- Understood the concept of **Virtual DOM**
- Installed Node.js
- Created first React project using **Vite**
- Ran React app locally


---

### ✅ Day 2 – JSX Basics
- Learned what JSX is (JavaScript + HTML)
- Displayed variables using JSX
- Performed calculations inside JSX
- Understood JSX rules (className, fragments, closing tags)


---

### ✅ Day 3 – Components
- Understood what React components are
- Created multiple components:
  - Header
  - Content
  - Footer
- Imported and rendered components inside `App.jsx`
- Built a simple page layout


---

### ✅ Day 4 – Props
- Learned how to pass data between components using **props**
- Created a reusable `Student` component
- Passed different values as props
- Rendered multiple components dynamically

---

### ✅ Day 5 – Small React Layout Practice
- Combined **JSX + Components + Props**
- Created a simple layout with:
  - Header
  - Profile
  - Footer
- Used JSX expressions
- Applied inline styling
- Improved confidence with React structure


---

### ✅ Day 6 – Mini Project: Profile Card UI
**Mini Project using React**

**Features:**
- Reusable `Card` component
- Displayed:
  - Profile Image (placeholder)

- Built a clean and attractive UI
